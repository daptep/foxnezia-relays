# foxnezia-relays

Аварийный список точек входа в API для приложения Foxnezia VPN.

Приложение обращается сюда, **только если не сработал ни один известный путь**:
ни закешированные relay, ни прямое подключение к бэкенду. В обычной жизни список
приходит клиенту от самого бэкенда (поле `relays` в каждом ответе) и кешируется на
устройстве — этот файл нужен ровно на случай, когда бэкенд недостижим и взять
свежий список больше неоткуда.

## Формат

```json
{ "relays": ["relay-1.example.com", "https://relay-2.example.com/api/mobile"] }
```

Достаточно голого хоста: клиент сам подставит `https://` и `/api/mobile`.

## Как обновлять

Правьте `relays.json` и коммитьте в `main` — клиенты читают файл напрямую:

- `https://raw.githubusercontent.com/daptep/foxnezia-relays/main/relays.json`
- `https://cdn.jsdelivr.net/gh/daptep/foxnezia-relays@main/relays.json` (зеркало, кеш до ~12 ч)

Держите здесь только имена, а не адреса: сервер под relay меняется A-записью
(TTL 300), и тогда ни этот файл, ни приложение трогать не нужно.
